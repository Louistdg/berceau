Pourquoi les familles s'y mettent

Vos photos sont dans un carton, vos dates dans un carnet, et ceux qui savaient sont partis. Un arbre familial local aide à réunir dates, lieux, liens et souvenirs dans un même espace.

👓

Lisible par tous

Gros caractères, contrastes vérifiés, 8 ambiances de couleurs — de la crème au mode nuit. Une personne de 80 ans peut lire sans plisser les yeux.

➕

Trois secondes par personne

Un bouton +, un prénom, une année. L'arbre se dessine tout seul. Pas de formulaire savant, pas de jargon.

🔒

Rien que pour vous

Aucun compte ni partage familial n'est configuré dans ce prototype. Les données saisies restent dans le navigateur de cet appareil.

Comment ça marche

Le prototype fonctionne dans un navigateur. Les données restent sur l'appareil jusqu'à leur export.

Commencez par vous

Ouvrez la démonstration fictive ou importez un GEDCOM que vous avez le droit d'utiliser.

Complétez les fiches

Les questions qu'on nous pose

Faut-il savoir se servir d'un ordinateur ?

Non. Si vous savez lire et cliquer sur un bouton, c'est suffisant. Le site est écrit en gros, avec un seul bouton important par écran, et chaque action est annoncée en clair.

Mes données sont-elles visibles par tout le monde ?

Les modifications sont conservées dans le navigateur de votre appareil. Elles ne sont pas synchronisées; exportez une sauvegarde pour les transférer.

Et si je veux arrêter ?

Exportez vos données généalogiques en GEDCOM, que les autres logiciels de généalogie peuvent lire. Utilisez la sauvegarde .berceau pour inclure les photos.

Où sont mes photos ?

Les photos optimisées sont conservées dans le navigateur. Une sauvegarde complète .berceau les inclut; le GEDCOM ne contient que les chemins de fichiers.

Ça marche sur téléphone ?

Une interface mobile existe, mais elle reste à vérifier sur téléphone réel avant de confier des données familiales.
